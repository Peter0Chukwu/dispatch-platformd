TWL — SMALL DEPLOY FIX (2 files)
================================

Why you are extracting this
---------------------------
The website container needs to know where the API container lives. Up to now that
address was baked in as "api:4000", which only works when both run on the same
Docker network. On the hosting platform each container gets its own internal
address, so the address is now a setting instead.

What to do
----------
1. Extract into your project folder (C:\Users\USER\Documents\dispatch-platform).
   Say YES to replace.

2. ONE FILE MUST BE DELETED — your unzip will not delete it for you:

       C:\Users\USER\Documents\dispatch-platform\deploy\nginx.conf

   It has moved to: deploy\nginx-templates\default.conf.template
   If the old file stays behind, the new one is ignored. Delete it.

3. Commit and push:

       git add -A
       git commit -m "deploy: configurable API address for the web image"
       git push

Nothing else changes. Your local Docker setup still works exactly as before,
because the setting defaults to api:4000.
