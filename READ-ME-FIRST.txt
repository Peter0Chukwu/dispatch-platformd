TWL — NEW LANDING PAGE
======================

What changed
------------
The public page was full of my working notes: the tech stack, a "Design system"
link, a live Postgres/Redis panel, and sentences explaining how the API works.
That is gone. The page now reads like a company page for a Benin City courier:

  - Headline and two sign-up buttons
  - Three steps: book, rider accepts, follow it to the door
  - Four reasons to trust it
  - The areas covered, named as streets
  - Five real questions answered
  - Footer with the two sign-in links

The login/sign-up pages and the customer home screen got the same treatment.

How to apply (2 steps)
----------------------
1. Extract into C:\Users\USER\Documents\dispatch-platform (say YES to replace).

2. Commit and push:

       git add -A
       git commit -m "landing page: written for traders, not for developers"
       git push

Then Northflank rebuilds the website automatically (CI/CD is green), about 3-4
minutes. Hard-refresh the site afterwards (Ctrl + Shift + R).
