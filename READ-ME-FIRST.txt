TRADERS WELFARE — GOOGLE MAPS CHANGE
====================================

WHAT THIS IS
  The fix for the map and the distance estimates, plus the guide for setting
  Google Maps up. Commit 8f2bb0f on top of 2b1fbcd.

HOW TO APPLY (VS Code Source Control tab first)
  1. Unzip this over your clone at C:\Users\USER\Documents\dispatch-platform,
     replacing the files it asks about.
  2. Open the Source Control tab. You should see 10 changed files plus one new
     file (backend/test/maps.google.spec.ts).
  3. Stage all, commit with the message in COMMIT-MESSAGE.txt (or anything you
     like — the code is what matters).
  4. Push.

IF YOU PREFER THE TERMINAL
  git apply --stat google-maps.patch      # look first
  git apply google-maps.patch
  git add -A && git commit -m "maps: current Google APIs, and no more internal notes"
  git push

THEN
  npm install                             # only if it complains about a missing module
  npm run build --workspace @dispatch/shared
  cd backend && npx tsc --noEmit && npx vitest run test/maps.google.spec.ts
  cd ../frontend && npx tsc --noEmit

READ NEXT
  GOOGLE-MAPS-SETUP.md — the four APIs to enable, the two keys to create, where
  each key goes, and how to check it worked. Enable "Places API (New)", Routes
  API, Geocoding API and Maps JavaScript API. NOT the old Places/Directions/
  Distance Matrix — Google stopped selling those on 5 October 2026 and a new
  project cannot turn them on.

NOTHING BREAKS IF YOU DO NOT
  With no key the app prices from real Benin City coordinates and a straight-line
  model, and the screens say "estimated distance" rather than pretending.
