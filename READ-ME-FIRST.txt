TRADERS WELFARE — MAPS NOW RUN ON GEOAPIFY
==========================================

WHAT THIS IS
  Maps without a Google Cloud account. Commit 54b30cc, on top of a3e2bfc.

  Geoapify: no card, no billing screen, 3,000 free requests a day, commercial
  use allowed with attribution, and ONE key covers address suggestions,
  geocoding, road distance/ETA and the map tiles themselves.

WHAT YOU DO (about five minutes)
  1. https://myprojects.geoapify.com/register  — email only, no card.
  2. Create a project, then copy its API key (one long string).
  3. Backend service environment:
         MAPS_PROVIDER=GEOAPIFY
         GEOAPIFY_API_KEY=your-key
  4. Web service environment:
         VITE_GEOAPIFY_API_KEY=your-key
     Same key. Bare, no quotes.
  5. REDEPLOY / REBUILD THE WEB SERVICE. Vite bakes VITE_ variables in at build
     time; restarting alone will not show the map.

HOW TO TELL IT WORKED
  · https://<your-api-host>/api/v1 now shows  maps: GEOAPIFY
  · Booking form: type "sapele" — the caption changes from "Popular Benin City
    locations." to "Address suggestions as you type."
  · A fare shows a road distance, and the tracking card says "Road route".
  · The tracking page shows a street map with "Powered by Geoapify".

IF IT DOES NOT WORK
  The API log names the failing call, e.g.
    Geoapify routing failed, falling back to the stub estimate:
    Geoapify routing responded 401
  401 = key wrong (often a stray quote). 403 = key deleted. 429 = too fast.
