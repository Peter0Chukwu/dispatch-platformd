TWL — SIGN-IN FIX + COPY CLEAN-UP
=================================

1. The Admin tab is gone from the public sign-in page
------------------------------------------------------
/login now shows only Customer and Rider.

Staff sign in at a page that is not linked anywhere public:

      https://your-site-url/staff

Bookmark it for yourself. Old links that say ?portal=admin now redirect there.

Nothing else changes: an admin account still opens the admin portal, and an
invited staff member still sets their password from the invitation link.

2. The notes are gone
---------------------
The seeded admin email and password hint is deleted from the login page. So is
"Protected by Argon2id". Other screens now say what they do for the person using
them instead of explaining the API:
  - customer home, booking, delivery progress
  - rider home, offers
  - verification and test-payment notices
  - admin: staff, reports, deliveries, finance, pricing
  - the 404 page is now a real page

3. How to apply
---------------
Extract into C:\Users\USER\Documents\dispatch-platform (say YES to replace), then:

      git add -A
      git commit -m "sign-in: staff door off the public page, notes replaced with real copy"
      git push

Northflank rebuilds automatically (3-4 minutes). Hard-refresh afterwards:
Ctrl + Shift + R.
